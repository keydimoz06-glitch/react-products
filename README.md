# React Products

Aplicación desarrollada en React + Vite que consume la API REST de DummyJSON para gestionar productos mediante operaciones de consulta, búsqueda, filtrado, creación, actualización y eliminación.

Aplicación de tienda en línea que permite listar, buscar, filtrar por categoría, paginar, crear, actualizar y eliminar productos consumiendo los endpoints de DummyJSON.
